## My Calculator

A simple calculator built using HTML, CSS and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear the display
- Percentage
- Square root
- Memory functions (M+, M-, MR, MC)
- Theme toggle (light/dark mode)
- Keyboard shortcuts for all operations (0-9, +, -, \*, /, ., %, Enter, Escape, Backspace)
- History panel (stores last 5 calculations)
- Error handling (division by zero, invalid operations)
- Responsive design (works on mobile and desktop)
- localStorage (stores decimal places preference)
- Clearablehistory button
- Decimal places preference selection button

## advance feature

- Exponential function (e^x)
- Power function (x^y)
- Square root function (√x)

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

Open the index.html file in a web browser.
